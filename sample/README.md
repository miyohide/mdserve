# サンプルドキュメント

これは **mdserve** の動作確認用のMarkdownファイルです。

## 機能一覧

- Markdownを見やすいHTMLに変換
- ディレクトリ一覧の表示
- 画像などの静的ファイル配信

## コード例

```typescript
console.log("Hello, mdserve!");
```

## 表

通常の表は、これまで通り静的に表示される。

| 項目 | 説明 |
| --- | --- |
| CLI | コマンドラインから起動 |
| サーバー | ローカルWebサーバー |

## 集計・フィルター・ソート付きの表

表の直前に `{.table-tools}` だけの段落を置くと、その表にフィルター・ソート・集計機能が付く。数値だけの列は下部に合計と平均が表示される。列見出しをクリックすると並べ替えられる。

{.table-tools}

| 商品 | 単価 | 数量 | 金額 |
| --- | --- | --- | --- |
| りんご | 120 | 3 | 360 |
| みかん | 80 | 10 | 800 |
| ぶどう | 400 | 2 | 800 |
| もも | 300 | 5 | 1500 |

> 引用ブロックの例です。
